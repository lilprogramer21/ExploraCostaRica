# Explora Costa Rica 🇨🇷
Proyecto académico desarrollado
con HTML y CSS.
## Objetivo
Crear un sitio web responsive
sobre Costa Rica y utilizar Git
y GitHub para administrar
las diferentes versiones.
## Tecnologías utilizadas
- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages
- Visual Studio Code
## Contenido
El proyecto contiene:
- Destinos turísticos
- Volcanes
- Playas
- Biodiversidad
- Experiencias
- Galería
- Gastronomía
- Parques nacionales
- Formulario
- Diseño responsive
